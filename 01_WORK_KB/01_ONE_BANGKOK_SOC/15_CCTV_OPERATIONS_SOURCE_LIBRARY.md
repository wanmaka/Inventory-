## Target Canonical Knowledge

CCTV Master KB should ultimately cover:

- CCTV Governance and authorization
- Request / view / copy / export workflow
- Live View and Playback operational use
- Camera types and Field of View (FoV)
- OBK layout context and camera mapping
- Evidence handling and record requirements
- Camera issue / offline / obstruction tracking
- Virtual Patrol interface
- Video Analytics interface
- Qognify/Easy7 operation where controlled source is available
- Troubleshooting and escalation
- Retention / request / approval constraints where source explicitly defines them
- Training and practical assessment references

## Restricted Data Rule

The following remain Drive-only unless specifically sanitized:

- CCTV footage/evidence
- identifiable person images
- case-level evidence
- detailed camera map/coverage data that increases security risk
- credentials/user secrets
- sensitive layout/access details

Public GitHub may store process, taxonomy, approved rules, generic operational principles and source metadata.

## Core control rules

- Google Drive remains the Raw Source / Source of Truth.
- `CURRENT_REV_CANDIDATE` = located in the latest revision area and filename indicates Signed/Revision, but Document Control verification still governs when ambiguity exists.
- `SOURCE_PRESENT` = source document located, but filename/location alone is not sufficient to prove approved current revision.
- `SUPERSEDED_SOURCE` = a higher revision exists for the same document code.
- `DRAFT` = draft source; never use as approved operational rule.
- `Obsolete`, `Cancelled`, `Historical`, `Not Start`, `On Process`, `Complete`, Signed status and revision conflicts must be preserved as source facts.
- Exact document code, filename and source reference must be retained for cross-reference.
